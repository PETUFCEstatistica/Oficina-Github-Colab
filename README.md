# Oficina-Github-Colab
Repositório template para a oficina de GitHub e Colab voltada à limpeza e análise exploratória de dados. Realizada no dia 12/11/2026, pelos alunos participantes do PET Estatística da Universidade Federal do Ceará. Neste projeto demonstramos como publicar um novo projeto, e tratar os dados através de notebooks Jupyter na plataforma Colab.
